314 language codes indexed from all providers. For each code, the table shows
which providers have at least one model supporting that language for STT and
for TTS. Regenerated at build time from `GET /v1/models`.

**Reading the table:**
- **Language** — BCP-47 code (lowercase primary tag, uppercase region). The `*` row at the bottom lists providers that claim broad language support without enumerating codes — they always appear in filtered queries.
- **STT providers** — have at least one model that accepts audio in this language
- **TTS providers** — have at least one model that synthesizes speech in this language
- `—` means no active provider in that category supports this language

## Query the API directly

The table is a snapshot. For a live, filtered list:

```bash
# All providers with Hindi STT models
curl "https://naaviq-voice-providers-production.up.railway.app/v1/models?type=stt&language=hi" \
  | jq '[.[] | .provider_id] | unique'

# All providers with Hindi TTS models
curl "https://naaviq-voice-providers-production.up.railway.app/v1/models?type=tts&language=hi" \
  | jq '[.[] | .provider_id] | unique'
```

Prefix matching applies: `?language=en` matches `en`, `en-US`, `en-GB`, and
`*`. `?language=en-IN` matches only `en-IN` and `*`. See
[Languages](/docs/concepts/languages) for details.
