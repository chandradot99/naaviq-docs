9,204 active TTS voices across 27 providers, grouped by provider. Each
section shows up to 12 voices — click the "see `/v1/providers/.../voices`"
link at the bottom of each section to fetch the full list via API.

**Reading the table:**
- **id** — the voice identifier to pass when calling the provider's TTS API
- **gender** — `female`, `male`, or `neutral`; `—` means the provider doesn't expose this field
- **languages** — BCP-47 codes this voice supports; `*` means the provider claims multilingual support without enumerating specific codes
- **preview** — a provider-hosted audio sample (`preview_url`); `—` means no sample is available

## Filter by language or gender

To search across all providers instead of scrolling:

```bash
# Female Hindi voices that have a preview
curl "https://naaviq-voice-providers-production.up.railway.app/v1/voices?language=hi&gender=female" \
  | jq '.[] | select(.preview_url != null) | {provider_id, name, preview_url}'

# All voices with emotion-control capability
curl "https://naaviq-voice-providers-production.up.railway.app/v1/voices?capabilities=emotion_control" | jq
```

See [Languages](/docs/concepts/languages) for the BCP-47 codes accepted by `?language=`.
